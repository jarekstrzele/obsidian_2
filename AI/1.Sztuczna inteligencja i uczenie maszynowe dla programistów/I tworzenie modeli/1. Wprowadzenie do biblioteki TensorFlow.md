# Czym jest TensorFlow

>[!info] TensorFlow
> - platforma oparta na zasadzie otwartego oprogramowania służąca do
> 	- tworzenia i 
> 	- stosowania modeli uczenia maszynowego

![[TenserFlow.png]]


==trenowanie==
- proces tworzenia modeli uczenia maszynowego
- komputer używa szeregu algorytmów, by poznać dane wejściowe i dowiedzieć się, co je od siebie odróżnia
- sposoby trenowania w **TensorFlow**:
	- samodzielna definicja logiki uczenia się, samodzielna jej implementacja
	- używanie *estymatorów* (zaimplementowane sieci neuronowe, ktore można modyfikować)
	- korzystanie z interfejsów API wyskokiego poziomu o nazwie ==Keras==, który umożliwia hermetyzację w kodzie typowych paradygmatów uczniea masyznowego
		- *TensorFlow Data Services* udostępniają wiele wstępnie przetworzonych zbiorów danych, które moga być dołączane do programu za pomocą pojedynczego wiersza kodu

==wnioskowanie==
- proces rozpoznawania lub kategoryzowania przyszyłych danych wejściowych

# MiniConda
>[!info] Conda
> Conda to menedżer pakietów i środowisk, który pozwala:
> > - Izolować projekty w oddzielnych środowiskach (z własnymi wersjami Pythona i bibliotek).
>> - Instalować/usuwać pakiety wraz z ich zależnościami.
>> - Eksportować i odtwarzać środowiska na innych maszynach.
>


## instalacja
Pobierz skrypt instalacyjny dla Twojego systemu z
- https://docs.conda.io/en/latest/miniconda.html

Na Linux/macOS w terminalu:
```bash
cd ~/Pobrane
chmod +x Miniconda3-latest-Linux-x86_64.sh
./Miniconda3-latest-Linux-x86_64.sh
# zaakceptuj licencję, wybierz ścieżkę (domyślną lub własną)

```

## praca z conda
`conda update conda`	Aktualizuje samego menedżera conda

`conda info` 	Pokazuje konfigurację (ścieżki, wersja itp.)

`conda list`  	Wyświetla zainstalowane pakiety w bieżącym env

`conda search numpy`  Wyszukuje pakiet numpy w dostępnych kanałach

`conda clean --all`	Czyści cache pakietów i metadata


## wirtualne środowiska
### tworzenie
**Domyślnie w katalogu envs** `~/miniconda3/envs`:
`conda create -n myenv python=3.12`

**wyłączenie automatycznego właczania* `base` w conda 
`conda config --set auto_activate_base false`

**w folderze projektu PyCharm**
```bash
cd ~/PycharmProjects/firstML
conda create --prefix ./env python=3.12

```


### aktywacia i dezaktywacja
```bash
conda activate myenv      # lub: conda activate ./env
# (myenv) ➜ oznacza, że środowisko jest aktywne

conda deactivate          # wyłącza aktywne env, wracasz do base lub “czystego” shella

```

### usuwanie
```bash
conda remove -n myenv --all      # usuwa całe środowisko myenv
conda env remove --prefix ./env  # usuwa env w katalogu projektu

```

## Instalacja pakietów
### Domyślny kanał vs. conda-forge
#### Domyślny (mniej aktualny, ale podstawowy):

```bash
conda install numpy pandas
```

#### conda-forge
częściej aktualizowany, więcej pakietów
```bash
conda install -c conda-forge numpy pandas
```

### Konkretne wersje
`conda install -c conda-forge tensorflow==2.19 keras==2.11`

### Mieszanie z pip
Gdy czegoś nie ma w Condzie:

`pip install sqlalchemy-utils`
Uwaga: najpierw użyj conda install, potem (ew.) pip install.


### Zarządzanie kanałami
Dodanie conda-forge na stałe:
```bash

conda config --add channels conda-forge
conda config --set channel_priority strict
```
Wyświetlenie kanałów:
`conda config --show channels`
