# Czym jest TensorFlow

>[!info] TensorFlow
> - platforma oparta na zasadzie otwartego oprogramowania służąca do
> 	- tworzenia i 
> 	- stosowania modeli uczenia maszynowego

![[TenserFlow.png]]


==trenowanie==
- proces tworzenia modeli uczenia maszynowego
- komputer używa szeregu algorytmów, by poznać dane wejściowe i dowiedzieć się, co je od siebie odróżnia
- sposoby trenowania w **TensorFlow**:
	- samodzielna definicja logiki uczenia się, samodzielna jej implementacja
	- używanie *estymatorów* (zaimplementowane sieci neuronowe, które można modyfikować)
	- korzystanie z interfejsów API wysokiego poziomu o nazwie ==Keras==, który umożliwia hermetyzację w kodzie typowych paradygmatów uczenia maszynowego
		- *TensorFlow Data Services* udostępniają wiele wstępnie przetworzonych zbiorów danych, które mogą być dołączane do programu za pomocą pojedynczego wiersza kodu

==wnioskowanie==
- proces rozpoznawania lub kategoryzowania przyszyłych danych wejściowych

### wyjaśnienie
![[Pasted image 20250514115713.png]]

Na tym rysunku są 3 warstwy:
- pierwsza ma 5 neuronów
- druga ma 4 
- trzecia ma 2

```python
model = Sequential([
    Dense(units=1, input_shape=[1])
])
```
- warstwy to `Sequental`
- nasz program ma jedną warstwę
- typ warstwy `Dense`:
	- gęsta
	- neurony zostały "gęsto" połączone (jak na rysynku, czyli każdy neuron z jednej warstwy jest połączony z każdym neuronem z warstwy drugiej)
	- `units=1` warstwa wykorzystuje tylko jeden neuron
	- `input_shape=[1]` 
		- to kształt danych, którą będą wprowadzane do neuronu
		- będą to pojedyncze liczby `[1]`
		- każda próbka wejściowa ma **1 cechę** (czyli wektor jednowymiarowy).


```python
model.compile(optimizer='sgd', loss='mean_squared_error')
```
- komputer nie wie, jaki jest związek między wartościami *X* i *Y*
- komputer będzie tę zależność zgadywał:
	- np. wystartuje od `Y=10X+10`
	- dla `X=-1` zwróci `0`, a prawidłowa to `-3`
	- dla `X=0` zwróci 10, a prawidłowa to `-1`
	- działa **funkcja straty** 
- teraz komputer zgaduje kolejny raz - **optymalizator** (rachunek różniczkowy) spróbuje zgadnąć lepiej n`oprimizer='sgd'` , czyli używamy optymalizatora `sgd`:
	- stochastyczny spadek wzdłuż gradientu - funkcja matematyczna
	- ma podane wartości + poprzednią prognozę + wartość błędu (straty) => generuje kolejną prognozę
	- optymalizator będzie starał się minimalizować straty
- `loss="mean_squared_error` Funkcja straty: `mean_squared_error` – błąd średniokwadratowy, typowy dla regresji.



```python
xs = np.array([-1.0, 0.0, 1.0, 2.0, 3.0, 4.0], dtype=float)
```

- `xs` to wektory wejściowe (czego sieć się uczy).

## czego nauczyła się sieć

```python
import numpy as np
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense

# nowa zmienna
lo = Dense(units=1, input_shape=[1])

#użycie nowej zmiennej
model = Sequential([
   lo
])
model.compile(optimizer='sgd', loss='mean_squared_error')

xs = np.array([-1.0, 0.0, 1.0, 2.0, 3.0, 4.0], dtype=float)
ys = np.array([-3.0, -1.0, 1.0, 3.0, 5.0, 7.0], dtype=float)

model.fit(xs, ys, epochs=500)

#print(model.predict([[10.0]]))
arr = np.array([10.0]).reshape(-1, 1)   # kształt (1,1)
print(model.predict(arr))
print(f"Nauczyłem się {lo} \n  {lo.get_weights()}") # wyświetlenie
print("end")


```

```python
[w_matrix, b_vector] = lo.get_weights()
```
`
`w_matrix` macierz wag (*kernel*)
- zawiera współczynniki, które są mnożone przez wartość wejściową
- kształt: `input_dim` oraz `units`

`b_vector` wektor biasów
- kształt `(units,)`
- zawiera stałą wartość dodawaną do wyniku iloczynu  wejścia i wagi

przykład:
```python
[array([[2.05]]), array([0.98])]
```
czyli sieć nauczyła się funkcji `y=2,05 * x + 0.98`
