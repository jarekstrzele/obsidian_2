# Variable

**variable** a name assigned  to a value in the program (it is a placeholder)

==snake_case_formatting==


 **assigning a value to a variable**
 `let apples = 50 ;`


```rust
fn main() {
    let apples = 50;
    let oranges = 15 + 3;
    let fruits = apples + oranges ;


	// macro
	println!("My fruits") ;
	
	//interpolate dynamic values
	println!("this year, my garden hase {} apples", fruits - 10) ;
	println!("this year, my garden hase {fruits - 10} apples and {oranges} pranges") ;


}
```

# Variable shadowing
#rust/shadowing


**variable shadowing**:
- means redeclaring  a variable 
- the original variable is "replaced" by the new one


```rust
fn main() {
    let a: &str = "123.32" ;
    let a: f64 = 123.333;
    let a: i32 = 123 ;
    println!("My a = {a}") ; // 123
}
```


# Scope
**scope** it is a boundary or region of code where name  is valid
**block** it is a area between an opening curly brace and a closing curly brace and a closing curly brace 
#rust/scope 

  ```rust
  fn main() {
   // the scope is the main function
   let abc = 123 ;
   
   // nested/ iner scope
   {
       println!("The abc = {abc}") ; // 123
       
       // its scope is only this inner 
       let inner_abc = 123 ;
       
       let abc = 345 ; // this is NOT shadowing 
       println!("The abc = {abc}") ; // 345
   }
   
   // println!("inner_abc {inner_abc}") ; // not found in this scope
   
   println!("The abc = {abc}") ; // 123
}
```


# Constants
#rust/constant
**constant** 
- it is a name assigned to a value
- a constants value cannot change


## constant vs immutable variable
| constant                                                                | variable                         |
| ----------------------------------------------------------------------- | -------------------------------- |
| - can be declared at any scope (can be declare outside of any function) | - is limited to a function scope |
| - must be known at compile time                                         | - is defined at runtime          |
| - explicite type annotation                                             | -                                |
|                                                                         |                                  |
 
```rust
const NAME: &str = "constant" ;

fn main() {
   let num = 34.56;
   println!("Name = {NAME}, num= {num}") ; //Name = constant, num= 34.56
   
}
```


# Type aliases
#tust/type_alias

**type alias** it is an alternate name that we can assign to an existing type
```rust
type Meters = i32 ;

fn main() {
   let mile_race_lenght: Meters = 34 ;
   println!("Race {mile_race_lenght} meters") ;
   
}
```


# Compile directives `#[ ]`
#rust/compile_directives

**compiler directive** it is an annotation that tells the compiler how to parse the source code

`#[allow(...)]` - this directive permits or allows a behavior that the compiler would otherwise raise

```rust
type Meters = i32 ;

fn main() {
    #[allow(unused_variables)]
    let mile_race_lenght: Meters = 34 ;
    #[allow(unused_variables)]
    let fruits_number: i32 = 142 ;
   
}
```

to whole function
```rust
type Meters = i32 ;

#[allow(unused_variables)]
fn main() {
    let mile_race_lenght: Meters = 34 ;
    let fruits_number: i32 = 142 ;
   
}
```

to whole file
```rust
#![allow(unused_variables)]


type Meters = i32 ;

fn main() {
    let mile_race_lenght: Meters = 34 ;
    let fruits_number: i32 = 142 ;
   
}
```
