# Definitions
>[!important] slice
> - It is a **reference** to a portion/sequence of a collection type
> 	- **a string slice** is a reference to a sequence of characters from a string
> 	- **an array slice** is a reference to a sequence of elements from an array
> - as a reference, a slice **does not take ownership** of the collection

**a collection type** is one that can hold multiple values 


# a string slice from a heap allocated String
```rust
fn main() {
    
    let action_hero: String = String::from("Arnold Schwarzanegger") ;
    let string_ref: &String = &action_hero ;
    println!("{string_ref}") ; //Arnold Schwarzanegger
    
    // slices
    
    let string_slice_name: &str = &action_hero[0..6] ; // byte range
    println!("{string_slice_name}") ; //Arnold
    
    let last_name: &str = &action_hero[7..21] ; // byte range, 21 is not included
    println!("{last_name}") ; //Schwarzanegger
}
```


# String slices and String Literals
**string literal** is declared with double quotes 

```rust

fn main() {
    
    let action_hero: &str = "Arnold Schwarzanegger";
    let string_ref: &str = &action_hero ;
    println!("{string_ref}") ; //Arnold Schwarzanegger
    
    // slices
    
    let string_slice_name: &str = &action_hero[0..6] ; // independent reference
    println!("{string_slice_name}") ; //Arnold
    
    let last_name: &str = &action_hero[7..21] ; // byte range, 21 is not included
    println!("{last_name}") ; //Schwarzanegger
    
    
    // the slice has an independent reference
    let abc: &str = {
        let new: &str = "something NEW" ;
        
        &new[10..13] 
    };
    println!("abc = {abc}") ; // abc = NEW
    
    
}
```



# String Slice Lengths

>[!info] a length of a string lice - `len()`
>the lendth of a string slice refers to a count of its BYTES, not its characters


```rust

fn main() {
    
    let food: &str = "pizza" ;
    println!("{}", food.len()) ; // 5
    
    let pizza_slice: &str = &food[0..3] ;
    println!("pizza_slice = {pizza_slice}, length = {}", pizza_slice.len()) ; //pizza_slice = piz, length = 3
    
    let food1: &str = "🍕🍕" ;
    let food1_slice: &str = &food1[4..8] ;
    println!("emoji len = {}", food1.len()) ; // emoji len = 8
    println!("One pizza {}", food1_slice) ; // One pizza 🍕
    
}
```

# String Slices as Function Parameters

```rust

fn do_hero_thing(hero: &str) {
    println!("{hero} does something") ;
}


fn main() {
    let arnold: String = String::from("Arnold") ;
    do_hero_thing(&arnold) ; // behind &String -> &str // Arnold does something
    
    let rambo: &str = "Rambo" ;
    do_hero_thing(rambo) ; // Rambo does something
    
}
```



# Array
#rust/array 

## array slices
```rust
fn main() {
    let values: [i32;6] = [4,8,15,16,23,42] ;
    
    let array_slice1: &[i32] = &values[..4] ; // [4, 8, 15, 16]
    println!("{array_slice1:?}") ;
   
    let array_slice2: &[i32] = &values[2..4] ; // [4, 8, 15, 16]
    println!("{array_slice2:?}") ;
    
    // difference between slice and ref (it is more restricted)
    let array_ref: &[i32;6] = &values ; // 6 elements
    let array_slice: &[i32] = &values[..] ; // any number of elements
    println!("array_ref {array_ref:?}") ; // array_ref [4, 8, 15, 16, 23, 42]
    println!("array_slice {array_slice:?}" ) ; // array_slice [4, 8, 15, 16, 23, 42]
    
}
```



## deref coercion with array slices

```rust
fn main() {
    let values: [i32;6] = [4,8,15,16,23,42] ;
    
    let regular_ref: &[i32;6] = &values;
    print_length(regular_ref) ; // 6
    
    let slice_of_three: &[i32] = &values[..3] ;
    print_length(slice_of_three) ; // 3
    
}

fn print_length(reference: &[i32]){
    println!("{}", reference.len()) ;
}
```


## mutable array slices

```rust

fn main() {
    let mut my_arr: [i32;5] = [10,15,20,25,30] ;
    
    let my_slice: &mut [i32] = &mut my_arr[2..4] ;
    println!("My slice {my_slice:?}") ; //My slice [20, 25]
    
    my_slice[0] = 1234 ;
    println!("My slice {my_slice:?}") ; // My slice [1234, 25]
    println!("My array {my_arr:?}") ; // My array [10, 15, 1234, 25, 30]
}
```
