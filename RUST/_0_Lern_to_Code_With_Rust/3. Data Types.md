# Data Type in Rust

- every Rust value has a data type
- Rust is a statically typed language, which means the compiler must know the types of all variables at compile time
- the compiler can infer the types of variables based on their initial assignments


# Data Type Categories in Rust

## Scalar types
- a scalar type is a type that holds a single value
- there are:
	- integers,
		- **signed integer** - positive and negative values (`i`)
		- **unsigned integer** - only zero and positive values (`u`)
	- floating-point
	- Booleans
	- characters

>[!info] Bits
>- the number after the `i` or `u` refers to the amount of bits the integer needs in your computer's memory
>- **bit** it is the smallest unit of computer memory. It represents a value of either 0 or 1
>- `8 bits` is equal to 1 **byte**
>- `1024` bytes **kilobyte**
>- `i32` requires 32 bits (4 bytes) of memory
>- `f64` requires 64 bits (8 bytes)
>

## Compound types
It is a collection of one or more value.
### array
- **an array** is a fixed-size collection of homogeneous data
- **elements** are values of an array
- it is stored on the stack at runtime

```rust
fn main() {
    let numbers: [i32; 5] = [4,2,4,8,54] ;

    let apples: [&str; 3] = ["Granny Smith" , "McIntosh", "Red Delicious"] ;
    
    println!("Length: {}", apples.len()) ; //Length: 3
    println!("numbers: {:?}", numbers) ; //numbers: [4, 2, 4, 8, 54]
    println!("apples[0] {} ", apples[0]) ; // apples [0] Granny Smith 
    
    let mut season: [&str; 4] = ["Spring", "Summer", "Fall", "Winter"] ;
    season[1] = "Lato" ;
    println!("season[1] {} ", season[1]); // season[1] Lato 
    
}
```

# Format specifier
**format specifier** customizes the printed representation of the interpolated value
```rust
fn main() {
    let pi: f64 = 3.1415926535897932384 ;
    println!("Pi = {pi}") ;        // Pi = 3.141592653589793 
    println!("Pi = {pi:.3}") ;     // Pi = 3.142
    println!("Pi = {:.5}", pi) ;   // Pi = 3.14159
}
```

# Casting with `as` keyword
**cast a value** means to transform it from one type into another

```rust
fn main() {
    let number: i32 = 323 ;
    println!("i32 {}", number) ;          // 323
    println!("i8 = {}", number as i8) ;   // 67 
    println!("u8 = {}", number as u8) ;   // 67 
    println!("f64 = {}", number as f64) ;   // 32   
}
```

## The Display Trait
#rust/trait_display

**contract in the Real World**
- a contract is a document that people sign that states  their obligations


**TRAITS**
- a trait is a contract that requires that a type support one or more methods
- traits establish consistency between types; methods that represent the same behavior have the same name
- when a type opts in to honoring a trait's requirements, we say the type implements the trait
- type can vary in their implementation but still implement the same trait


- a type can choose to opting in to implementing a trait
- a type can implement multiple traits (there are hundreds of traits available in Rust
- a trait is called an interface or protocol in other programming languages

>[!info] the Display Trait
>- the display trait requires that a type can be represented as a user-friendly, readable string
>- the Display trait mandates a format method that returns the string
>- when we use the {} interpolation syntax, Rust relies on the format method
>- Integers, floats, and booleans all implement the Display trait so we are able to interpolate them with curly braces
>
>- It is not always clear how a complex type should be represented as a piece of text
>- Not all types implement the Display trait. One example is the array type.


# A New Macro `dbg!`
`dbg!` prints and returns the value of a given expression for quick and dirty debugging
#rust/dbg 
```rust
fn main() {
    let some_str: [&str; 3] = ["tom", "jerry", "franio"] ;
   
    println!("This is 5 {some_str:#?}") ;

    This is 5 [
    "tom",
    "jerry",
    "franio",
    ]
    */
    dbg!(some_str) ;
    /*
    [src/main.rs:12:5] some_str = [
    "tom",
    "jerry",
    "franio",
    ]
    */


    println!("{}", 2+2) ; // 4
    dbg!(2+2) ; // [src/main.rs:23:5] 2+2 = 4

}
```

# Tuple `( ... )`
#rust/tuple 

```rust
fn main() {
    let dog = ("Rufus", 2, true, "Owczarek") ;
    let name = dog.0 ;
    println!("Name: {name}, age {}", dog.1 ) ; //Name: Rufus, age 2

    dbg!(dog) ;
    /*
    [src/main.rs:6:5] dog = (
    "Rufus",
    2,
    true,
    "Owczarek",
    )
    */
    println!("Dog {dog:?}") ; // Dog ("Rufus", 2, true, "Owczarek")
    
    
    let (name2, age, good, bread) = dog;
    println!("{name2}, {age}, {good}, {bread}") ; //Rufus, 2, true, Owczarek
    
}
```

# Ranges
# `<start>..<endNotIncluded>` or
# `<start>..=<end>`
#rust/range 
**range** is a sequence/interval of consecutive values
**iterate** means to progress over the elements of a collection one by one

```rust
fn main() {
    let week_days = 1..=7;
    println!("week_days {week_days:#?}") ; //week_days 1..=7
    for day in week_days{
        print!("days: {day} ") ;
    } // days: 1 days: 2 days: 3 days: 4 days: 5 days: 6 days: 7 
    
    println!("-------") ;
    let letters = 'g'..'s' ;
    for l in letters{
        print!("{l}, ") ;
    } //g, h, i, j, k, l, m, n, o, p, q, r, 

    
    
}
```
