# Recursion
**recursion** is when a function calls itself
```rust
fn count_down(s: i32){
	if s == 0{
		println!("Blastoff!!")
	} else{
		println!("{s} seconds to blastoff..");
		count_down(s - 1 ) ;
	}
}
    
    
fn main() {

    count_down(5);
/*
5 seconds to blastoff..
4 seconds to blastoff..
3 seconds to blastoff..
2 seconds to blastoff..
1 seconds to blastoff..
Blastoff!!
*/
}
```
