**reference** stores the memory address of a value
**borrowing** mean creating a reference











---------

**immutable reference**
```rust
fn main() {
   let mut current_meal: String = String::from("Humburger") ;
   show_my_meal(&current_meal) ; //Meal: Humburger
}


fn show_my_meal(meal: &String){
    println!("Meal: {meal}") ;
}
```

**mutable references**
```rust
fn main() {
   let mut current_meal: String = String::from("Humburger") ;
   show_my_meal(&current_meal) ; //Meal: Humburger
   add_drink(&mut current_meal) ;    
   show_my_meal(&current_meal) ; // Meal: Humburger add coca cola

}

fn add_drink(meal: &mut String){
    meal.push_str(" add coca cola") ;
}

fn show_my_meal(meal: &String){
    println!("Meal: {meal}") ;
}

/*
PARAMETERS:
- move
    - meal: String
    - mut meal: String
- borrow
    - meal: &String
    - meal: &mut String


*/
```



>[!danger] immutable references
> Rust permits **any number** of immutable references to the same value
```rust
fn main() {
    let car: String = String::from("red");
    let ref1: &String = &car ;
    let ref2: &String = &car ;
    
    println!("ref1 = {ref1}, ref2 = {}", ref2) ; // ref1 = red, ref2 = red
}

```


>[!danger] mutable reference
>The value can only have a **single** mutable reference at a time, because
>
>the mutable reference has permission to mutate the value, while the immutable reference expects that data at that location  to remain what it originally was.
> e
> it doesn't implement the Copy trait

```rust
fn main() {
    let mut car: String = String::from("red"); // it is an owner
    let ref1: &mut String = &mut car ; // it is a borrower
    ref1.push_str(" some new") ;
    
    let ref2: &String = &car ;
    
    println!("ref2 = {}", ref2) ; // ref2 = red some new
    
    //but that code generates an error
   // println!("ref1 = {}", ref1) ; //---- mutable borrow later used here
    // 
    // from   let ref2: &String = &car ; ->
    // error[E0502]: cannot borrow `car` as
    //immutable because it is also borrowed as mutable
}
```

# Ownership with Immutable and Mutable References

>[!success] immutable reference
> An immutable reference implements the Copy trait

>[!success] mutable reference
> An mutable reference DOESN'T implement the Copy trait

```rust
fn main() {
   let coffee: String = String::from("Mocha") ;
   let a: &String = &coffee; //Rust will create a full copy of this immutable reference
   // and assign it to 'b'
   let b: &String = a; // be represents a copy, a separate entry on the stack
   // a separate immutable reference that it is the owner of
    
    println!("a = {a}"); //  a = Mocha
    println!("b = {b}"); //  b = Mocha
}

```


```rust
fn main() {
   let mut coffee: String = String::from("Mocha") ; // the owner of the String
   let a: &mut String = &mut coffee; // a is the owner of the mutable reference
   // and assign it to 'b'
    println!("a = {a}"); //  'a' is valide
   
   let b: &mut String = a; // // the ownership of a is moved to b
   // the ownership of a is moved to b
   
    
    println!("a = {a}"); //  'a' is invalide
    println!("b = {b}"); // 
}

```



**The code will not compile because a mutable reference cannot coexist with another reference.**
```rust
fn main() {
	let mut candy = String::from("M&M's");
	let some_ref = &mut candy;
	let another_ref = &candy;
	println!("{some_ref} and {another_ref}");
}
```

# Dangling References

>[!important] dangling reference
>It is a pointer to a memory address that has been deallocated

dangling reference
```rust
fn main() {
   let reference: &String = create_city();
   
}

fn create_city() -> &String {
    let city: String::from("New York") ;
    
    &city // this is a dangling reference
}
```

the correct code
```rust
fn main() {
   let reference: String = create_city();
   
}

fn create_city() -> String {
    
    String::from("New York") 
    
}
```

# Ownership with Arrays and Tuples
**ownership** is answering the question: ==who is responsible for cleaning this data up==


ARRAY
```rust
fn main() {
    //registration is responsible for cleaing up data-array
    // array is the owner ot its internal elements (bools)
    let registration: [bool;3] = [true, false, true] ;
    
    // Boolean implements the Copy trait
    let first = registration[0]; // Rust creates a full copy
    
    println!("{first} and {registration:?}") ; // true and [true, false, true]
   

    ////////////////
    // the languages owns an array
    // the array wons two String elements
    let languages = [String::from("Rust"), String::from("JavaScript")];
    
    // String doesn't implement the Copy trait
    // error[E0508]: cannot move out of type `[String; 2]`, a non-copy array
    
    // let first_string = languages[0];// ownership is moved from the array owner to the 
    
    // 'first_string' variable
    
    
    //solution 1
    let first_string_clone = languages[0].clone();
    
    //solution 2
    let first_string_by_ref = &languages[0] ;

    
    println!("clone {first_string_clone}, ref {first_string_by_ref} ") ; //clone Rust, ref Rust 
}
```
