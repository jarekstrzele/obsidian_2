#rust/function 

**function** a sequence of steps to be executed in order

`fn main() { }`

**parameter** a name for an expected input to a function
**argument** the concrete value passed in for a parameter when the function is invoked

```rust
fn main(){
	open_store("Brooklyn") ;

}



fn open_store(neighborhood: &str){
	println!("Opening my pizza store in {neighborhood}");
}
```


**return value** the output of a function
==Every Rust function must have a return value!!!==
```rust
fn square(num: i32) -> i32 {
	return num*num ;
}
```

or
**whatever is the last line's value will automatically be the return value**
```rust
fn square(num: i32) -> i32 {
	
	num*num 
}
```

#rust/unit
**unit** an empty tuple, a tuple without values `()`
```rust
fn mystery() {} //the return value will be unit `()`
fn mystery()->(){} // but ->() is not necessary
```
