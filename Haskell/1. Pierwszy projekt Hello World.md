Main.hs
```haskell
module Main (main) where

main :: IO ()
main = putStrLn "Hello, world"
```

`module Main (main) where` :
- deklaracja modułu - każdy plik w Haskellu to moduł
- `Main` to nazwa modułu, (aplikacja Haskellowa musi mieć punkt startowy w module `Main`)
- `(main)` eksportujemy tylko funkcję `main`

`main`
- ma typ `IO()` - to akcja wejścia/wyjścia - coś, co może mieć efekt uboczny
- `()` to wartość jednostkowa, coś jak `void` w innych językach (`main` nie zwraca niczego sensownego)
